# Domain docs

Amigo uses a single-context domain layout.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read relevant decisions under `docs/adr/`.
- Proceed silently when a referenced domain document does not exist.

## Vocabulary

Use terminology defined in `CONTEXT.md` for issue titles, acceptance criteria, tests, and
implementation proposals. Avoid introducing synonyms for established concepts.

## Architecture decisions

Surface any conflict with an existing ADR explicitly. Do not silently override a documented
decision.
