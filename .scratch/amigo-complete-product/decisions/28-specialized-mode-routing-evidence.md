# Validate Specialized Mode Releases and Switching Friction

Parent: [Amigo Complete Product](../MAP.md)
Status: open
Label: `wayfinder:task`
Type: HITL / task
Severity: `severity:high`
Owner: unassigned
Blocked by: [Choose the Mode and Adaptive Coaching Contract](14-mode-and-adaptation-contract.md)

## Question

Collect the release and usage evidence required to determine whether automatic Mode routing or
unconfirmed Interaction Style adaptation is ready to be reconsidered.

## Completion checklist

- Identify at least two specialized Modes that have independently passed every release gate in the
  approved Mode contract.
- Record observed switching friction, mistaken Mode entry, override behavior, and participant
  requests without prompting participants toward automatic routing.
- Record the qualifying Modes, gate evidence, friction evidence, and evidence locations.
- If fewer than two Modes qualify, record that the automatic-routing decision remains dormant.

## Comments

Until this task and the dependent decision close with approval, Mode entry remains explicit and
Interaction Style changes remain participant-confirmed.
