# Collect Durable Memory Demand Evidence

Parent: [Amigo Complete Product](../MAP.md)
Status: open
Label: `wayfinder:task`
Type: HITL / task
Severity: `severity:high`
Owner: unassigned
Blocked by: [Choose the Memory and Memory Inspector Trust Contract](13-memory-trust-contract.md)

## Question

Collect the beta evidence required to decide whether durable Memory should enter a limited opt-in
release and therefore needs a storage and retrieval technology decision.

## Completion checklist

- Record participant-reported continuity problems without suggesting durable Memory as the answer.
- Confirm whether at least three Beta Participants independently report a problem that the approved
  explicit-first Memory contract could solve.
- Record the problem statements, participant count, evidence locations, and whether the demand gate
  passed without copying sensitive conversation content into this tracker.

## Comments

Memory remains disabled by default. Completing this task records demand evidence only; it does not
authorize implementation or relax the trust contract.
